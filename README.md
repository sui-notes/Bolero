# Bolero

A remote control for [TuneBrowser](https://tikisoft.net/) (a Windows music player), for Android.

- Website: https://sui-notes.github.io/Bolero/
- Privacy Policy: https://sui-notes.github.io/Bolero/privacy-policy.html

Bolero is an independent app and is not affiliated with the developer of TuneBrowser.
