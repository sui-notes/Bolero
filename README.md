# Bolero Music Control

A remote control for [TuneBrowser](https://tikisoft.net/) and [foobar2000](https://www.foobar2000.org/) (Windows music players), for Android.

- Website: https://sui-notes.github.io/Bolero/
- Privacy Policy: https://sui-notes.github.io/Bolero/privacy-policy.html

Bolero is an independent app and is not affiliated with the developers of TuneBrowser or foobar2000.

---

スマホから PC の TuneBrowser・foobar2000 を操作するリモコンアプリ Bolero の公開ページです (プライバシーポリシーなど)。
